# Dabbler

A responsive handmade-crochet storefront built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run lint
npm run build
```

## Before launch

- Replace the Instagram link in `src/App.tsx` with Dabbler's profile.
- Update product details and availability in the `products` list in `src/App.tsx`.
- Add current prices and order/contact information.
- Product enquiry buttons currently show a demo message; connect them to a real
  ordering channel when one is available.

Product images are stored in `src/assets`.
